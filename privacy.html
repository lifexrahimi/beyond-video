Effective November 19, 2026 · Applies to Beyond Video Factory (the "App")

Who uses the App

The App is a private tool operated solely by the owner of the Beyond Video YouTube channel. It is not available to the public, and it only ever signs in to the channel owner's own Google account.

Data the App accesses

With the channel owner's permission (Google OAuth), the App uses YouTube API Services to:

  • upload videos to the owner's channel and set their titles, descriptions, tags, privacy/schedule, thumbnails, captions and playlists;
  • read the owner's channel information and YouTube Analytics reports (views, watch time, retention, subscribers and, where available, estimated revenue) for the owner's own videos;
  • read public YouTube data (video titles, descriptions, statistics and public comments) to research trending topics.

How data is stored and used

All data is stored locally on the owner's own computer (an SQLite database and local files) and is used only to produce, publish and improve the channel's own videos. OAuth tokens are stored in a local file readable only by the owner's account. The App does not sell, share, or transfer any data to third parties, and does not use it for advertising.

YouTube API Services

The App uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google security settings – third-party access. Locally stored data can be deleted by removing the App's data folder; stored analytics are kept for at most 90 days of history and can be deleted on request to the contact below.
